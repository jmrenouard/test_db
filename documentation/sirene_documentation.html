Section 01 · Architecture & Pipeline

Sirene PostgreSQL 17 3NF ETL Platform

Idempotent, high-throughput Python 3.12 and PostgreSQL 17 pipeline designed to ingest, normalize into strict Third Normal Form (3NF), geocode (EPSG:2154 Lambert-93 to WGS84), and continuously synchronize the French INSEE Sirene business registry from data.gouv.fr Parquet and compressed CSV distributions.

PostgreSQL 17-bookworm pg_trgm GIN Fuzzy Search COPY FROM STDIN Streaming Pure-Python GRS80 Geocoder SHA-256 Idempotent Watcher

Idempotent 3NF Schema & Sentinels

Seven INSEE referential dimensions pre-seeded with deterministic sentinel keys (UNK, UNK00, 00.00Z, 0000, NN, UN) plus dynamic HIST auto-registration guarantee foreign keys never fail on obsolete or missing codes.

Bulk COPY + Index Lifecycle

full_import.py acquires advisory lock 84729101, drops non-constraint secondary indexes via drop_secondary_indexes(), streams 50,000-row batches via COPY FROM STDIN, deduplicates on primary key, merges changes, and rebuilds all 25 indexes with ANALYZE.

Monotonic Delta & Audit Trail

incremental_import.py wraps updates in a single top-level PostgreSQL transaction, prevents stale overwrites via date_dernier_traitement monotonic guards, preserves non-null date_creation, and logs every A <-> F state change into etablissements_historique_etat.

Autonomous data.gouv.fr Watcher

watcher.py polls the dataset API on WATCHER_INTERVAL_SECONDS=3600 (or --once), inspects SHA-256 checksums, last_modified, and resource_id against etl_logs, and automatically routes empty databases to full load or populated ones to incremental sync.

Sole Proprietor & Role Graph

Legal units with legal category 1xxx (or natural persons lacking a corporate denomination) are deterministically projected using SHA-256(SIRENE_EI|<siren>) into personnes and linked in roles_entreprises with UNIQUE NULLS NOT DISTINCT.

Sirene v3.11 Edge-Case Hardening

Handles [ND] non-diffusible placeholders as SQL NULL, strips trailing whitespace in Sirene CSV headers (such as "coordonneeLambertAbscisseEtablissement "), creates 'C'/'P' orphan SIREN placeholders, and validates SHA-256 digests in 1 MiB streaming chunks.

Quickstart & Makefile Orchestration

Every lifecycle task runs through root Makefile targets backed by sirene/docker-compose.yml. Copy sirene/.env.example to sirene/.env first if you want custom parameters (defaults bind loopback port 15432 to avoid colliding with local PostgreSQL on 5432).

1. Start PostgreSQL 17 Container 
make sirene-up
Starts sirene-postgres (postgres:17-bookworm), applies sirene/sql/ on fresh volume init, and waits for healthcheck.
2. Build & Run Full Pytest Suite 
make sirene-test
Builds sirene-etl and runs unit transforms, live PostgreSQL 17 integration, 15-query SQL, and governance/doc checks.
3. Initial Full-Stock Bulk Import 
make sirene-import ARGS="--offline-refs --limit-rows 10000"
Runs python full_import.py (omit ARGS for full production stock download from data.gouv.fr).
4. Incremental Delta Sync 
make sirene-incremental
Executes transactional delta synchronization with monotonic timestamp guards and A <-> F history tracking.
5. Autonomous Watcher Daemon 
make sirene-watch
Starts sirene-watcher under Compose profile daemon polling data.gouv.fr every 3600s.
6. Documentation Paths & Stack Down 
make sirene-docs && make sirene-down
Prints links to interactive HTML and bilingual Markdown docs, and cleanly stops Compose services/profiles.

Q03

Unified pg_trgm Fuzzy Search Across Legal Units, Trade Signs & Persons

Fuzzy pg_trgm

Splits each trigram % predicate into its own CTE branch so the PostgreSQL planner activates all three GIN indexes in parallel, then ranks matched SIRENs by highest similarity() score.

Tables: unites_legales, etablissements, personnes, roles_entreprises · Indexes: idx_ul_nom_trgm, idx_etab_enseigne_trgm, idx_personnes_nom_trgm 
WITH search_params AS (
    SELECT 'ACME TECHNOLOGIE'::TEXT AS query_text
),
ul_matches AS (
    SELECT
        ul.siren,
        'LEGAL_UNIT'::TEXT AS match_source,
        ul.nom_recherche AS matched_text,
        similarity(ul.nom_recherche, sp.query_text) AS trgm_score
    FROM unites_legales ul
    CROSS JOIN search_params sp
    WHERE ul.nom_recherche % sp.query_text
),
etab_matches AS (
    SELECT
        e.siren,
        'ESTABLISHMENT_SIGN'::TEXT AS match_source,
        e.enseigne_recherche AS matched_text,
        similarity(e.enseigne_recherche, sp.query_text) AS trgm_score
    FROM etablissements e
    CROSS JOIN search_params sp
    WHERE e.enseigne_recherche % sp.query_text
),
person_matches AS (
    SELECT
        re.siren,
        'PERSON_ROLE'::TEXT AS match_source,
        p.nom_complet_recherche AS matched_text,
        similarity(p.nom_complet_recherche, sp.query_text) AS trgm_score
    FROM personnes p
    CROSS JOIN search_params sp
    JOIN roles_entreprises re
        ON re.personne_id = p.id
    WHERE p.nom_complet_recherche % sp.query_text
),
combined_matches AS (
    SELECT * FROM ul_matches
    UNION ALL
    SELECT * FROM etab_matches
    UNION ALL
    SELECT * FROM person_matches
)
SELECT
    cm.siren,
    ul.etat_administratif,
    ul.nom_recherche AS legal_unit_search_name,
    ul.code_naf,
    ROUND(MAX(cm.trgm_score)::NUMERIC, 4) AS best_similarity_score,
    ARRAY_AGG(DISTINCT cm.match_source ORDER BY cm.match_source) AS matched_dimensions,
    STRING_AGG(DISTINCT cm.matched_text, ' | ') AS matched_labels
FROM combined_matches cm
JOIN unites_legales ul
    ON ul.siren = cm.siren
GROUP BY
    cm.siren,
    ul.etat_administratif,
    ul.nom_recherche,
    ul.code_naf
ORDER BY
    best_similarity_score DESC,
    cm.siren
LIMIT 25;

Q06

WGS84 Bounding-Box & Haversine Radius Search (km) + Lambert-93 Distance

Geo & Spatial

Pre-filters active geocoded establishments inside a WGS84 bounding box around Paris, computes numerically safe Haversine spherical distance (clamped via LEAST(1.0, ...)), and compares against EPSG:2154 planar Euclidean distance.

Tables: etablissements, unites_legales · Indexes: idx_etab_etat_administratif, unites_legales_pkey 
WITH geo_anchor AS (
    SELECT
        48.856600::DOUBLE PRECISION AS center_lat,
        2.352200::DOUBLE PRECISION AS center_lon,
        652469.02::DOUBLE PRECISION AS center_l93_x,
        6862035.26::DOUBLE PRECISION AS center_l93_y,
        25.0::DOUBLE PRECISION AS radius_km,
        0.25::DOUBLE PRECISION AS lat_delta,
        0.35::DOUBLE PRECISION AS lon_delta
),
candidate_sites AS (
    SELECT
        e.siret,
        e.siren,
        COALESCE(ul.denomination, ul.nom_recherche) AS legal_unit_name,
        e.enseigne_1,
        e.code_naf,
        e.adresse_complete,
        e.longitude,
        e.latitude,
        e.coord_lambert_x,
        e.coord_lambert_y,
        (
            6371.0 * 2.0 * ASIN(
                SQRT(
                    LEAST(
                        1.0,
                        POWER(SIN(RADIANS(e.latitude - ga.center_lat) / 2.0), 2) +
                        COS(RADIANS(ga.center_lat)) * COS(RADIANS(e.latitude)) *
                        POWER(SIN(RADIANS(e.longitude - ga.center_lon) / 2.0), 2)
                    )
                )
            )
        ) AS haversine_km,
        CASE
            WHEN e.coord_lambert_x IS NOT NULL AND e.coord_lambert_y IS NOT NULL THEN
                SQRT(
                    POWER(e.coord_lambert_x::DOUBLE PRECISION - ga.center_l93_x, 2) +
                    POWER(e.coord_lambert_y::DOUBLE PRECISION - ga.center_l93_y, 2)
                ) / 1000.0
            ELSE NULL
        END AS lambert93_km,
        ga.radius_km
    FROM etablissements e
    JOIN unites_legales ul
        ON ul.siren = e.siren
    CROSS JOIN geo_anchor ga
    WHERE e.etat_administratif = 'A'
      AND e.latitude IS NOT NULL
      AND e.longitude IS NOT NULL
      AND e.latitude BETWEEN (ga.center_lat - ga.lat_delta) AND (ga.center_lat + ga.lat_delta)
      AND e.longitude BETWEEN (ga.center_lon - ga.lon_delta) AND (ga.center_lon + ga.lon_delta)
)
SELECT
    siret,
    siren,
    legal_unit_name,
    enseigne_1,
    code_naf,
    adresse_complete,
    longitude,
    latitude,
    ROUND(haversine_km::NUMERIC, 3) AS distance_wgs84_km,
    ROUND(lambert93_km::NUMERIC, 3) AS distance_lambert93_km
FROM candidate_sites
WHERE haversine_km <= radius_km
ORDER BY
    haversine_km ASC,
    siret
LIMIT 50;

NAF 5-Level Hierarchy Rollup (Section → Division → Groupe → Classe → Sous-classe)

Computes hierarchical establishment and distinct legal-unit totals from grand total down through every NAF Rev. 2 classification tier using PostgreSQL GROUP BY ROLLUP and GROUPING() level tags.

Tables: etablissements, ref_naf · Indexes: idx_etab_code_naf, ref_naf_pkey 
SELECT
    CASE
        WHEN GROUPING(n.code_section) = 1 THEN 'GRAND_TOTAL'
        WHEN GROUPING(n.code_division) = 1 THEN '1_SECTION'
        WHEN GROUPING(n.code_groupe) = 1 THEN '2_DIVISION'
        WHEN GROUPING(n.code_classe) = 1 THEN '3_GROUPE'
        WHEN GROUPING(n.code_naf) = 1 THEN '4_CLASSE'
        ELSE '5_SOUS_CLASSE'
    END AS hierarchy_level,
    n.code_section,
    n.libelle_section,
    n.code_division,
    n.libelle_division,
    n.code_groupe,
    n.code_classe,
    n.code_naf,
    n.libelle_sous_classe,
    COUNT(e.siret) AS total_establishments,
    COUNT(e.siret) FILTER (WHERE e.etat_administratif = 'A') AS active_establishments,
    COUNT(DISTINCT e.siren) AS distinct_legal_units
FROM etablissements e
JOIN ref_naf n
    ON n.code_naf = e.code_naf
GROUP BY ROLLUP (
    (n.code_section, n.libelle_section),
    (n.code_division, n.libelle_division),
    (n.code_groupe, n.libelle_groupe),
    (n.code_classe, n.libelle_classe),
    (n.code_naf, n.libelle_sous_classe)
)
ORDER BY
    n.code_section NULLS LAST,
    n.code_division NULLS LAST,

Administrative Closure & Reopening Churn Audit ('A' <-> 'F')

Audit & Ops

Inspects etablissements_historique_etat to report the latest administrative state transition per SIRET, classifying CLOSURE ('A' -> 'F') vs. REOPENING ('F' -> 'A') and linking the triggering etl_logs import batch.

Tables: etablissements_historique_etat, etablissements, unites_legales, ref_naf, ref_communes, etl_logs · Indexes: idx_etab_hist_siret, etablissements_pkey, unites_legales_pkey 
WITH ranked_transitions AS (
    SELECT
        h.id AS history_id,
        h.siret,
        e.siren,
        COALESCE(ul.denomination, ul.nom_recherche) AS legal_unit_name,
        e.code_naf,
        n.libelle_sous_classe AS activity_label,
        c.libelle AS municipality,
        h.ancien_etat,
        h.nouvel_etat,
        h.date_effet,
        h.changed_at,
        l.run_type,
        l.file_name,
        COUNT(*) OVER (PARTITION BY h.siret) AS transitions_for_siret,
        ROW_NUMBER() OVER (
            PARTITION BY h.siret
            ORDER BY h.changed_at DESC, h.id DESC
        ) AS transition_rank
    FROM etablissements_historique_etat h
    JOIN etablissements e
        ON e.siret = h.siret
    JOIN unites_legales ul
        ON ul.siren = e.siren
    JOIN ref_naf n
        ON n.code_naf = e.code_naf
    JOIN ref_communes c
        ON c.code_commune = e.code_commune
    LEFT JOIN etl_logs l
        ON l.id = h.etl_log_id
)
SELECT
    history_id,
    siret,
    siren,
    legal_unit_name,
    code_naf,
    activity_label,
    municipality,
    ancien_etat,
    nouvel_etat,
    CASE
        WHEN ancien_etat = 'A' AND nouvel_etat = 'F' THEN 'CLOSURE'
        WHEN ancien_etat = 'F' AND nouvel_etat = 'A' THEN 'REOPENING'
        ELSE 'OTHER_TRANSITION'
    END AS transition_category,
    transitions_for_siret,
    date_effet,
    changed_at,
    run_type,
    file_name
FROM ranked_transitions
WHERE transition_rank = 1
ORDER BY
    changed_at DESC,
    history_id DESC
LIMIT 100;

Data Quality Audit: [ND] Partial Diffusion & HIST / UNK Referentials

Audit & Ops

Audits statut_diffusion = 'P' rows (where Sirene [ND] fields were scrubbed to NULL), sentinel fallbacks ('UNK00', '00.00Z', '0000', 'UN'), auto-registered 'HIST' codes, and orphan 'C' placeholder SIRENs.

Tables: unites_legales, etablissements, ref_communes, ref_naf · Indexes: idx_etab_code_commune, idx_etab_code_naf, idx_ul_code_cj 
WITH quality_metrics AS (
    SELECT
        1 AS sort_order,
        'LEGAL_UNITS_PARTIAL_DIFFUSION_P'::TEXT AS metric_name,
        COUNT(*) FILTER (WHERE statut_diffusion = 'P') AS affected_rows,
        COUNT(*) AS total_scope_rows
    FROM unites_legales
    UNION ALL
    SELECT
        2,
        'ESTABLISHMENTS_PARTIAL_DIFFUSION_P',
        COUNT(*) FILTER (WHERE statut_diffusion = 'P'),
        COUNT(*)
    FROM etablissements
    UNION ALL
    SELECT
        3,
        'ESTABLISHMENTS_SENTINEL_COMMUNE_UNK00',
        COUNT(*) FILTER (WHERE code_commune = 'UNK00'),
        COUNT(*)
    FROM etablissements
    UNION ALL
    SELECT
        4,
        'ESTABLISHMENTS_HISTORICAL_OR_INACTIVE_COMMUNE',
        COUNT(*) FILTER (WHERE c.type_commune = 'HIST' OR c.est_active = FALSE),
        COUNT(*)
    FROM etablissements e
    JOIN ref_communes c
        ON c.code_commune = e.code_commune
    UNION ALL
    SELECT
        5,
        'ESTABLISHMENTS_HIST_OR_SENTINEL_NAF',
        COUNT(*) FILTER (WHERE n.nomenclature = 'HIST' OR n.code_naf = '00.00Z'),
        COUNT(*)
    FROM etablissements e
    JOIN ref_naf n
        ON n.code_naf = e.code_naf
    UNION ALL
    SELECT
        6,
        'LEGAL_UNITS_FALLBACK_CJ_0000_OR_TRANCHE_UN',
        COUNT(*) FILTER (WHERE code_cj = '0000' OR code_tranche_effectifs = 'UN'),
        COUNT(*)
    FROM unites_legales
    UNION ALL
    SELECT
        7,
        'LEGAL_UNITS_ORPHAN_PLACEHOLDER_C',
        COUNT(*) FILTER (
            WHERE etat_administratif = 'C'
              AND denomination IS NULL
              AND nom_naissance IS NULL
        ),
        COUNT(*)
    FROM unites_legales
)
SELECT
    metric_name,
    affected_rows,
    total_scope_rows,
    ROUND(100.0 * affected_rows / NULLIF(total_scope_rows, 0), 2) AS affected_pct

Q15

ETL Operational Health (etl_logs SHA-256) & Table/Index Storage Introspection

Audit & Ops

Combines per-entity latest ETL execution metrics (run type, status, SHA-256 digest, duration, cumulative rows) with pg_stat_user_tables live/dead tuple counts and PostgreSQL heap + index disk footprint.

Tables & Views: etl_logs, pg_stat_user_tables · Indexes: idx_etl_logs_entity_status_finished 
WITH latest_per_entity AS (
    SELECT
        id,
        run_type,
        entity_type,
        file_name,
        file_version,
        checksum_type,
        checksum_value,
        rows_processed,
        rows_inserted,
        rows_updated,
        status,
        started_at,
        finished_at,
        ROW_NUMBER() OVER (
            PARTITION BY entity_type
            ORDER BY started_at DESC, id DESC
        ) AS rn
    FROM etl_logs
),
entity_aggregates AS (
    SELECT
        entity_type,
        COUNT(*) AS total_runs,
        COUNT(*) FILTER (WHERE status = 'SUCCESS') AS success_runs,
        COUNT(*) FILTER (WHERE status = 'FAILED') AS failed_runs,
        COALESCE(SUM(rows_processed) FILTER (WHERE status = 'SUCCESS'), 0) AS cumulative_rows_processed,
        MAX(finished_at) FILTER (WHERE status = 'SUCCESS') AS last_success_at
    FROM etl_logs
    GROUP BY entity_type
),
etl_health AS (
    SELECT
        'ETL_RUN_HEALTH'::TEXT AS audit_scope,
        ea.entity_type AS subject_name,
        lp.run_type AS latest_run_type,
        lp.status AS latest_status,
        lp.file_name AS latest_file_name,
        lp.checksum_value AS latest_sha256_or_checksum,
        lp.rows_processed AS rows_or_live_tuples,
        lp.rows_inserted AS inserted_or_dead_tuples,
        lp.rows_updated AS updated_rows,
        ROUND(EXTRACT(EPOCH FROM (lp.finished_at - lp.started_at))::NUMERIC, 2) AS latest_duration_seconds,
        ea.total_runs,
        ea.success_runs,
        ea.failed_runs,
        ea.cumulative_rows_processed,
        NULL::TEXT AS table_size_pretty,
        NULL::TEXT AS indexes_size_pretty,
        NULL::TEXT AS total_size_pretty,
        ea.last_success_at AS last_event_or_analyze_at
    FROM entity_aggregates ea
    JOIN latest_per_entity lp
        ON lp.entity_type = ea.entity_type
       AND lp.rn = 1
),
table_storage AS (
    SELECT
        'PG_TABLE_STORAGE'::TEXT AS audit_scope,
        s.relname::TEXT AS subject_name,
        NULL::TEXT AS latest_run_type,
        NULL::TEXT AS latest_status,
        NULL::TEXT AS latest_file_name,
        NULL::TEXT AS latest_sha256_or_checksum,
        s.n_live_tup AS rows_or_live_tuples,
        s.n_dead_tup AS inserted_or_dead_tuples,
        NULL::BIGINT AS updated_rows,
        NULL::NUMERIC AS latest_duration_seconds,
        NULL::BIGINT AS total_runs,
        NULL::BIGINT AS success_runs,
        NULL::BIGINT AS failed_runs,
        NULL::BIGINT AS cumulative_rows_processed,
        pg_size_pretty(pg_relation_size(s.relid)) AS table_size_pretty,
        pg_size_pretty(pg_indexes_size(s.relid)) AS indexes_size_pretty,
        pg_size_pretty(pg_total_relation_size(s.relid)) AS total_size_pretty,
        GREATEST(s.last_analyze, s.last_autoanalyze) AS last_event_or_analyze_at
    FROM pg_stat_user_tables s
    WHERE s.schemaname = 'public'
)
SELECT *
FROM etl_health
UNION ALL
SELECT *
FROM table_storage
ORDER BY
    audit_scope,
    subject_name;
